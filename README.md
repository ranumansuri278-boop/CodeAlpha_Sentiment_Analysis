CodeAlpha Sentiment Analysis

Project Overview

This project performs Sentiment Analysis on Amazon Customer Reviews using Python. It classifies customer reviews into three categories: Positive, Negative, and Neutral.

Objectives

- Analyze customer reviews.
- Identify positive, negative, and neutral sentiments.
- Understand customer opinions.
- Visualize sentiment distribution.

Technologies Used

- Python
- Pandas
- Matplotlib
- VADER Sentiment Analysis

Dataset

Amazon Customer Review Dataset.

Project Workflow

1. Load the customer review dataset.
2. Explore and understand the data.
3. Handle missing review text.
4. Apply VADER sentiment analysis.
5. Classify reviews into Positive, Negative, and Neutral.
6. Generate sentiment counts.
7. Save results and visualizations.

How to Run the Project

Install the required libraries:

pip install pandas matplotlib vaderSentiment

Run the Python file:

python sentiment_analysis.py
